# team/vent: двойник вентиляции и газа шахты «Арқа-1»

```text
mine.json ─▶ model.py (сеть, газ, пожар, люди) ─▶ simulator.py ──MQTT telemetry/<twin>──▶ Ditto ─▶ Telegraf ─▶ InfluxDB ─▶ Grafana
                 ▲                     │                ▲
            advisor.py (нормы,         │ HTTP :8095     │ события opentwins/.../kz.arqa/dispatch
            прогноз 60 мин)            ▼                │
                                 ui/index.html ──команда──▶ Ditto: kz.arqa:dispatch
```

| Файл | Что делает |
|---|---|
| `mine.json` | Шахта: узлы, 11 выработок (длина, сечение, сопротивление R), ГВУ, датчики, бригады, места пожаров, физические параметры, нормы Приказа № 351 и источники цифр |
| `model.py` | Модель. **Воздух:** законы Кирхгофа, квадратичный закон сопротивления, кривая вентилятора h = h0·s² − h2·Q², естественная тяга, реверс, регуляторы, дросселирование пожаром; решение методом Ньютона по контурным расходам. **Перенос:** CH₄, CO, дым и нагрев по ячейкам около 50 м, против потока, с дисперсией и смешением в узлах. **Источники:** газовыделение лав (часть зависит от работы комбайна, то есть от наличия напряжения) и выработанного пространства по реальному профилю метана; пожар с ростом t², выходом CO и сажи; самонагревание. **АГЗ:** автоматическое отключение участка. **Люди:** выход по кратчайшему безопасному пути (Дейкстра, штраф за дым и CO), самоспасатели, доза CO по Пурсеру (FED) |
| `advisor.py` | Проверки по Приказу МИР РК № 351 и прогноз: каждый вариант решения прогоняется на копии двойника на 60 мин, варианты сравниваются по людям в дыму и метане, потере способности к самоспасению и времени выше нормы |
| `simulator.py` | Сервис: модель в ускоренном времени, публикация 35 двойников, приём команд через двойник `dispatch`, HTTP API и пульт |
| `setup_twins.py` | Создание двойников в Ditto с иерархией `_parents` |
| `ui/index.html` | Пульт диспетчера: разрез, сценарии, управление, советник, графики |
| `grafana/` | Дашборд и генератор `make_dashboard.py` |
| `data/` | Неделя реальных данных метана, CC BY 4.0 |
| `test_model.py` | 13 тестов физики и советника (`make mine-test`) |

## HTTP API (порт 8095)

| Запрос | Что делает |
|---|---|
| `GET /api/state` | Полное состояние: ячейки выработок, вентиляторы, участки, бригады, тревоги, прогноз |
| `GET /api/layout`, `GET /api/history` | Геометрия; история датчиков |
| `GET /api/twins` | Двойники `kz.arqa:*` из Ditto |
| `POST /api/command` `{"cmd": "fire", "arg": "fire-main"}` | Команда; идёт через двойник `kz.arqa:dispatch` в Ditto |
| `POST /api/sim` `{"speed": 30, "paused": false}` | Скорость модели |

Команды: `fan_trip`, `fan_start`/`fan_stop` (`arg`: `fan-1`/`fan-2`), `fan_reverse`, `fan_normal`, `fan_repair`, `methane_rise` (`arg`: участок, `factor`), `co_rise`, `fire` (`arg`: `fire-main`, `fire-l1-conv`, `fire-l2-ret`), `extinguish`, `power_off`/`power_on` (`arg`: `d-l1`, `d-l2`, `d-main`), `evacuate` (`arg`: участок или `all`), `regulator` (`arg`: выработка, `opening` 0,05–1), `reset`.

Переменные окружения: `SIM_SPEEDUP` (по умолчанию 10, задаётся через `VENT_SPEEDUP` в `make mine`), `VENT_PORT` (8095).
