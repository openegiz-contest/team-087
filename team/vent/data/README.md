# Данные

`methane_week_2014-03-24.csv` — неделя (24–30 марта 2014 г., 10 020 минут) реальных данных
системы мониторинга действующей угольной шахты в Польше: средние за минуту показания
метанометров MM256 и MM264 (% CH₄), анемометра AN311 (м/с) и тока комбайна AMP1_IR (А).

- Источник: Sikora M., Wróbel Ł. *Methane*. Mendeley Data, V1, 2021.
  DOI [10.17632/yd7vw4c5mk.1](https://doi.org/10.17632/yd7vw4c5mk.1).
- Лицензия: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Изменения: из исходного файла (1 с, 9,2 млн строк, 34 столбца) взяты 4 столбца,
  усреднены по минутам и вырезана одна неделя. Скрипт агрегации — в описании ниже.

Как используется: показание MM256, делённое на среднее за неделю, задаёт множитель
газовыделения лав и выработанных пространств (`model.Model._profile_factor`). Модель
начинает с понедельника 06:00 этой недели, поэтому смены с работой комбайна, выходные
и всплески газовыделения повторяют реальные.

Агрегация (исходный zip скачивается со страницы набора):

```python
import zipfile, io, csv
r = csv.reader(io.TextIOWrapper(zipfile.ZipFile("methane_data.zip").open("methane_data.csv")))
# группировка строк по (год, месяц, день, час, минута) и среднее по MM256, MM264, AN311, AMP1_IR
```
